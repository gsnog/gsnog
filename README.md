## 📚 Featured Repositories

### 🏛️ Enterprise Architecture & Design Patterns
Projects focused on complex business logic, scalability, and clean architecture.
- [💸 PIX Transfer Engine](https://github.com/gsnog/motor-pix) - Implementation of **Chain of Responsibility** and **Open/Closed (SOLID)** principles for a thread-safe financial validation pipeline, processing DTOs with immutable calculations (`BigDecimal`).

### ⚙️ Java Web Fundamentals (No Frameworks)
Developed to consolidate core web concepts, HTTP routing, and native database communication.
- [🐾 Veterinary Clinic Management](https://github.com/gsnog/gestao-clinica-veterinaria) - Collaborative web system built with **pure MVC architecture**. Developed using Java (**Jakarta Servlets**), manual database communication via **JDBC + PostgreSQL** (DAO Pattern), and secure data flow using **DTOs**.

### 🐳 Infrastructure & Real-World Databases
Focus on data persistence, containers, and database versioning.
- [💻 Equipment Inventory API](https://github.com/gsnog/inventario-empresa) - Real-world transition using **Docker, PostgreSQL, and Flyway** (Migrations). Ensuring integrity with `UNIQUE` constraints and disabling Hibernate's `ddl-auto`.
- [🎫 Corporate Helpdesk API V2](https://github.com/gsnog/api-helpdesk-v2) - Advanced relational mapping (`1:N`), dynamic migrations with **Flyway**, security simulation via `@RequestHeader`, and data protection using Spring Boot's **`@Transactional`**.
